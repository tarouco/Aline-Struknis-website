# Slots de foto

Salve cada arquivo real nesta pasta com o nome exato que o HTML espera. Assim que o arquivo
existir, a placa desenhada sai de cena sozinha — sem editar código.

| Arquivo | Onde aparece |
|---|---|
| `hero.webp` | abertura da home |
| `ingredientes.webp` | seção do método |
| `clinica.webp` | Clínica Strunkis |
| `curso.webp` | material do Projeto Strunkis Premium |
| `rede.webp` | consultório da rede de parceiras |
| `exemplo.webp` | exemplo de plano alimentar |
| `protocolo-caneta.webp` · `protocolo-natural.webp` | páginas de trilha |
| `boost.webp` `boost-1.webp` `boost-2.webp` `boost-3.webp` `boost-kit.webp` `boost-revenda.webp` | linha Boost Natural Foods |
| `caso-1a.webp` … `caso-6b.webp` | antes (`a`) e depois (`b`) de cada caso |

Formato `.webp`, foto na proporção que o slot pede (o CSS recorta com `object-fit: cover`).
Casos antes/depois só entram com autorização de uso de imagem assinada.
